# react-native-http-inspector

In-app network inspector for React Native. Drop-in UI to view HTTP requests and responses, with an interactive JSON tree for payloads.

## Installation


```sh
npm install react-native-http-inspector
```


## Usage


```js
import { multiply } from 'react-native-http-inspector';

// ...

const result = multiply(3, 7);
```
